# v0.55 Dublonen für alle – SQL ausführen (nur Alp)

**Voraussetzung:** App-Version v0.55.0 ist live (unten links „v0.55.0“). Sie funktioniert mit und ohne dieses SQL.

1. Supabase öffnen → Projekt **fkqsjcschvgvbofrpnco** → links **SQL Editor** → **+ New query**
   (direkt: https://supabase.com/dashboard/project/fkqsjcschvgvbofrpnco/sql/new).
2. Im Repo die Datei `supabase/v0.55-dublonen-sicherheit.sql` öffnen, **alles** kopieren, in das Feld einfügen.
3. Unten rechts **Run** drücken. Erwartet: „Success. No rows returned“ (Hinweise „… does not exist, skipping“ sind normal).
4. Kurz prüfen: neue Query `select count(*) from public.shop_rewards;` → **Run** → Ergebnis `0` (noch keine Buchungen).

**Danach testen:** eine echte Partie mit mindestens 3 Konten, mindestens 6 Minuten. Am Siegertreppchen steht dann z. B. „+2 Mitgespielt · +10 Quartette · +10 Sieg = +22“, und der Kontostand im Shop steigt.

**Zurück, falls etwas hakt:** neue Query `drop trigger if exists games_guard on public.games;` → Run. Damit ist der Wächter sofort aus; gebuchte Dublonen bleiben.

Was die Datei macht und warum: `supabase/v0.55-sicherheit-vorschlag.md`.
